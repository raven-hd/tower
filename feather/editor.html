Редактор выпусков

Изменения сохраняются сразу в архив на GitHub. Отдельная публикация не нужна.
Как пользоваться редактором
  1. Обычно просто откройте редактор: текущий еженедельный выпуск загрузится автоматически.
  2. Добавляйте события, новости, учеников и дни рождения. Для ссылки выделите нужную фразу и нажмите значок цепочки.
  3. Фотографии можно выбрать прямо в карточке. В предпросмотре они видны сразу, даже до публикации GitHub Pages.
  4. Перед сохранением нажмите «Предпросмотр». Кнопка «Сохранить изменения» сразу обновляет archive.json.
  5. «Новый выпуск» сам подставляет следующий номер. При новом семестре нумерация начинается с №1, а свиток номер не занимает.
После сохранения публичная страница может обновиться не мгновенно: GitHub Pages иногда требуется немного времени.
Резервные копии JSON — редко нужны
Для обычной работы эти кнопки не нужны: история GitHub уже хранит версии архива. Импорт стоит использовать только для восстановления.
