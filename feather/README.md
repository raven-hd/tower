# tower/feather — этап 01

Это первый безопасный перенос Перышка в новый репозиторий `raven-hd/tower`.

## Что уже работает

- публичный архив читает `./data/archive.json`;
- старые выпуски перенесены;
- сова, конверты и внешний вид листовки сохраняются;
- редактор загружает архив с сайта;
- есть заготовка `Создать следующий выпуск`;
- код готов к подключению Cloudflare Worker для сохранения прямо в GitHub.

## Временный мост

Графические файлы и фотографии на этом этапе временно грузятся из старого
`raven-hd.github.io/feather`. Это сделано специально, чтобы новый архив можно
было запустить и проверить до физического переноса бинарных ассетов. После
проверки мы перенесем их в `tower/feather/assets` и уберем старые абсолютные URL.

## Важно

Пока `apiUrl` в `config.js` пустой, редактор не сможет публиковать изменения в
GitHub автоматически. Это подключим на следующем этапе через Cloudflare Worker.
